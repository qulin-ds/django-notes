# 📝 Django Notes · Лабораторная по Python

Командное приложение для личных заметок: регистрация, вход, создание и редактирование, поиск и доступ только к своим записям.

**Авторы:** Андрей Сырчин и Артём Мастеров. **Стек:** Python · Django · SQLite · Bootstrap.

## Мой вклад

По [README общего исходного репозитория](https://github.com/l1234-tech/1_sem_hacaton_mast_syr), Артём Мастеров работал над представлениями (`views`), формами (`forms`), маршрутами (`urls`), статическими файлами (`static`) и административным интерфейсом (`admin`).

[Представления](notes/views.py) · [Формы](notes/forms.py) · [Маршруты](notes/urls.py) · [Статические файлы](static) · [Admin](notes/admin.py)

## Запуск

```sh
python -m venv .venv
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Запускайте установку и команды через Python из активированного окружения. Откройте `http://127.0.0.1:8000` и зарегистрируйте свой аккаунт. Старая база не включена: миграции создадут пустую локальную SQLite.

## Структура

`notes/` — модели, формы, представления и тесты; `templates/` — интерфейс; `static/` — оформление; `config/` — настройки проекта.

## Тесты

